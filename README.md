## Todo: Simple Battle & Grouwth
### 1. Simple Battle
- **Player to Enemy**: Player attacks the enemy with a simple close attack
- **Enemy to Player**: Enemy run into the player and attack him
### 2. Growth
- Level, Exp system management is done at GameManager.cs
- When enemies die, they drop experience value items. Players can earn experience value items.
- When Level Up, the game pauses and the player regains a bit of hp. and the player receives a reward list and selects a reward within that list, and the game resumes.
